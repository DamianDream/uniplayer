# Uniplayer

**Видеоплеер в одном HTML-файле.** Положите его на любой хостинг, передайте ссылку на видео — и он работает. Без сборки, без сервера, без подписок на видеоплатформу.

```
https://ваш-сайт/player/index.html?src=https://cdn.example.com/lesson/master.m3u8&title=Урок 1
```

Плеер сделан для онлайн-курсов и закрытых уроков, но подходит для любого видео, которое вы храните сами: на Cloudflare R2, Bunny, S3 или своём сервере.

---

## Почему он

**Ваше видео, ваш хостинг.** Плеер не привязан к платформе. Сегодня видео лежит на Cloudflare R2, завтра на другом CDN — ссылки для зрителей менять не придётся.

**Встраивается куда угодно.** Одна строка `<iframe>` — и плеер стоит на Webflow, Tilda, в личном кабинете или на лендинге. Всё поведение задаётся параметрами в адресе.

**Выглядит нейтрально.** Спокойная тёмная панель и белые иконки подходят к любому сайту. Нужен фирменный цвет — один параметр `accent`.

**Не перегружен.** Только то, что нужно зрителю урока: качество, скорость, субтитры, перемотка, продолжение с места остановки.

---

## Возможности

### Для зрителя

- Адаптивное качество HLS с ручным выбором, а также MP4, WebM и MOV
- Скорость от 0,5× до 2×, плеер её запоминает
- Субтитры: из потока HLS или отдельными файлами, язык запоминается
- Продолжение с того места, где остановился
- Превью кадра при наведении на полосу перемотки
- Управление с клавиатуры и жестами на телефоне (двойное касание ±10 с)
- Интерфейс на украинском, русском и английском — по языку браузера

### Для владельца

- **Короткие ссылки** на свои уроки: `?v=курс/урок` вместо длинного адреса
- **Водяной знак** канала и зрителя поверх видео
- **Списки разрешённого**: откуда брать видео и на каких сайтах можно встраивать плеер
- **Режим без перемотки** для уроков, которые нужно посмотреть целиком
- **Нет кнопки «Скачать»**, отключено меню правой кнопки
- **Аналитика просмотров**: кто начал, кто дошёл до середины, кто досмотрел
- Все настройки в одном маленьком файле `player.config.js`; сам плеер править не нужно

### Для разработчика

- События и команды через `postMessage`: `play`, `pause`, `seek`, прогресс, завершение
- Никаких зависимостей, кроме hls.js; её копия лежит рядом, запасная — на CDN
- Демо-страница с отладкой: видно, какие параметры плеер получил и какие события отправил

## Быстрый старт

**1. Загрузите на сайт** `index.html`, `hls.min.js` и при необходимости `player.config.js`.

**2. Дайте ссылку зрителю** или вставьте плеер на страницу:

```html
<iframe src="https://ваш-сайт/player/index.html?src=https%3A%2F%2Fcdn.example.com%2Flesson%2Fmaster.m3u8"
        style="width:100%;aspect-ratio:16/9;border:0"
        allow="autoplay; fullscreen"></iframe>
```

**3. Настройте под себя** в `player.config.js`:

```js
window.UNIPLAYER_CONFIG = {
  defaultBase: "https://cdn.ваш-сайт",       // короткие ссылки ?v=курс/урок
  watermark: "Название канала",
  allowedParents: ["ваш-сайт"]               // встраивать можно только у себя
};
```

Без файла настроек плеер тоже работает: любое видео по `https` через `?src=`.

## Попробовать локально

```bash
cd demo
npm install
npm run dev
```

Браузер откроет демо сам (`http://127.0.0.1:5173/`). Нужен Node.js 22.13 или новее; демо собрано на Vite.

Демо устроено как настоящий сайт: страница и плеер в iframe открываются с разных адресов, события просмотра принимает сервер и складывает в базу SQLite. На странице можно менять параметры, отправлять плееру команды, смотреть события и записи аналитики.

Самому плееру Node.js и сборка не нужны — только демо.

### Как проверить своё видео

1. Запустите демо командами выше.
2. В блоке «Параметры в адресе iframe» выберите в списке «Видео» пункт «своя ссылка».
3. В поле ниже вставьте адрес видео:
   - **видео в интернете** — полная ссылка, например `https://cdn.example.com/lesson/master.m3u8`;
   - **файл с компьютера** — создайте папку `demo/public/`, положите в неё файл (например `lesson.mp4`) и вставьте `http://127.0.0.1:5173/lesson.mp4`. Перезапускать демо не нужно, в git эта папка не попадает.
4. Нажмите «Применить и перезагрузить плеер».

Что смотреть на странице:

| Блок | Что показывает |
|---|---|
| «Что получил плеер» | какие параметры пришли из адреса, какие из `demo/player.config.js`, тип видео и его размер |
| «События от плеера» | что плеер сообщает странице: запуск, пауза, перемотка, прогресс, ошибки |
| «База событий» | что записалось в аналитику и воронку по каждому видео |

Чтобы проверить настройки владельца (водяной знак, списки разрешённого, запрет перемотки), правьте `demo/player.config.js` и снова нажимайте «Применить»: этот файл действует только в демо и не затрагивает рабочий `player.config.js` в корне.

Если вместо видео появилось «Эта ссылка не поддерживается», проверьте, что адрес ведёт прямо на файл и что он не закрыт списком `allowedHosts`.

## Что стоит знать заранее

- **Это не DRM.** Плеер убирает простые способы скачать видео, но технически подкованный зритель сохранит поток. Для важного контента используйте HLS вместо MP4.
- **Видео должно быть доступно по прямой ссылке.** Страницы YouTube, Vimeo или Google Drive не подойдут.
- **Для HLS и субтитров с другого домена нужен CORS** на стороне хранилища.
- **На реальных iPhone и Android плеер пока не проверялся** — только в Chrome на компьютере и в эмуляции.
