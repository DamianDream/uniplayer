# Универсальный плеер: параметры (props)

Один HTML-файл (`index.html`). Воспроизводит видео **с любого сайта**: Cloudflare R2, Bunny, S3, свой сервер и т.д. Что показывать и как, задаётся параметрами в адресе страницы.

Связанные заметки: [[video-r2-instrukciya|Инструкция: видео в R2]] · [[Скрипт prepare_video.sh — описание]] · [[R2 + CDN — условия и стоимость]]

> Это отдельный файл. Первый плеер (`/player/index.html?v=…`) остаётся как был, ссылки на него продолжают работать.

---

## Быстрый старт

1. Положите `index.html` на сайт, например в `/player-v2/`.
2. Ссылка для зрителя:
```
https://astakhova.com.ua/player-v2/index.html?src=https://cdn.astakhova.com.ua/amm/urok-zakritij-kanal/master.m3u8&title=Урок для закритого каналу
```

---

## Что умеет воспроизводить

| Формат | Как распознаётся | Выбор качества | Чем играет |
|---|---|---|---|
| **HLS** (`.m3u8`) | по расширению или `type=hls` | да | hls.js (загружается, только если нужен); на iPhone — встроенный плеер |
| **DASH** (`.mpd`) | по расширению или `type=dash` | да | dash.js (загружается, только если нужен) |
| **Файл**: MP4, WebM, MOV, OGG | всё остальное или `type=file` | нет (одно качество) | встроенный плеер браузера |

**Не подходят:** ссылки на страницы YouTube, Vimeo, Google Drive, Telegram и т.п. Это не файлы видео, а страницы с их собственным плеером. Нужна прямая ссылка на `.m3u8`, `.mpd` или `.mp4`.

## Параметры

| Параметр | Пример | По умолчанию | Что делает |
|---|---|---|---|
| **`src`** | `src=https://…/master.m3u8` | — | **ссылка на видео** (обязательно, если нет `v`) |
| `v` | `v=amm/urok-zakritij-kanal` | — | короткая запись для видео на `cdn.astakhova.com.ua`: плеер сам добавит `/master.m3u8`. Совместимо со старым плеером |
| `type` | `type=hls` / `dash` / `file` | авто | указать формат явно, если в ссылке нет расширения |
| `poster` | `poster=https://…/cover.jpg` | авто для HLS | обложка до запуска. Для `…/master.m3u8` плеер сам ищет рядом `poster.jpg` |
| `title` | `title=Урок 2. Воронка` | — | название в верхней части плеера и во вкладке браузера |
| `t` (или `start`) | `t=90`, `t=1:30`, `t=1m30s` | — | начать с нужного момента |
| `autoplay` | `autoplay=1` | выкл. | запустить сразу. Браузеры разрешают это только **без звука**, поэтому видео начнёт со звуком выключенным |
| `muted` | `muted=1` | выкл. | начать без звука |
| `loop` | `loop=1` | выкл. | повторять по кругу |
| `speed` | `speed=1.25` | `1` | начальная скорость, от 0.25 до 4 |
| `accent` (или `color`) | `accent=e3262f` | `e3262f` | цвет прогресса, активных кнопок и фавикона, HEX без `#` |
| `lang` | `lang=uk` / `ru` / `en` | `uk` | язык подписей и сообщений |
| `resume` | `resume=0` | вкл. | запоминать место, где зритель остановился (`0` — отключить) |
| `embed` | `embed=1` | выкл. | без скруглённых углов, для вставки в iframe |
| `fit` | `fit=cover` | `contain` | `cover` — заполнить рамку целиком с обрезкой краёв (удобно для вертикального видео в горизонтальной рамке) |

Включить флаг можно и без значения: `&autoplay&muted`. Выключить — `=0`, `=false` или `=off`.

### Важно про ссылки внутри `src`

Если в ссылке на видео есть свои параметры (`?token=…&expires=…`), её нужно **закодировать**, иначе плеер решит, что это его собственные параметры:

```
❌ index.html?src=https://site.com/video.m3u8?token=abc&expires=123
✅ index.html?src=https%3A%2F%2Fsite.com%2Fvideo.m3u8%3Ftoken%3Dabc%26expires%3D123
```

Закодировать можно в консоли браузера командой `encodeURIComponent("ссылка")` или любым онлайн-кодировщиком URL.

## Примеры

**Наш урок из R2 (HLS):**
```
index.html?src=https://cdn.astakhova.com.ua/amm/urok-zakritij-kanal/master.m3u8&title=Урок для закритого каналу
```

**То же коротко:**
```
index.html?v=amm/urok-zakritij-kanal&title=Урок для закритого каналу
```

**Обычный MP4 с любого сайта, с обложкой, с 2-й минуты:**
```
index.html?src=https://example.com/files/promo.mp4&poster=https://example.com/files/promo.jpg&t=2:00
```

**Тизер на лендинге: сразу без звука, по кругу, в фирменном цвете:**
```
index.html?src=https://cdn.astakhova.com.ua/amm/teaser/master.m3u8&autoplay=1&loop=1&accent=ff5a36&embed=1
```

**DASH:**
```
index.html?src=https://example.com/stream/manifest.mpd&lang=en
```

### Вставка на страницу (Webflow, лендинг)

```html
<iframe src="https://astakhova.com.ua/player-v2/index.html?v=amm/urok-zakritij-kanal&embed=1"
        style="width:100%;aspect-ratio:16/9;border:0"
        allow="autoplay; fullscreen; picture-in-picture" allowfullscreen></iframe>
```
Для вертикального видео: `aspect-ratio:9/16`.

## Управление

| Действие | Мышь / клавиатура | Телефон |
|---|---|---|
| Пуск / пауза | клик по видео, `Пробел`, `K` | кнопка в центре или на панели |
| −10 / +10 секунд | кнопки «10», `←` / `→`, `J` / `L` | двойное касание левой или правой части видео |
| Показать / скрыть панель | движение мыши | одиночное касание |
| Перемотка | клик или перетаскивание по полосе | перетаскивание по полосе |
| Громкость | ползунок, `↑` / `↓`, `M` — без звука | кнопкой телефона |
| Полный экран | кнопка, двойной клик, `F` | кнопка (на Android горизонтальное видео само поворачивает экран; на iPhone открывается системный полноэкранный режим, кнопки «Скачать» в нём нет) |
| Скорость | меню `1×`: 0.5× … 2× | то же |
| Качество | меню ⚙ (для HLS и DASH): Авто / 1080p / 720p … | то же |

Плеер запоминает громкость и место остановки для каждого видео (до конца просмотра).

**Фавикон** (иконка во вкладке браузера) повторяет кнопку запуска: светло-серый круг с треугольником в цвете `accent`. Он встроен в сам `index.html` как SVG, отдельный файл хостить не нужно.

## Защита от скачивания

**Что сделано:**
- **нет кнопки «Скачать»:** используются собственные кнопки управления, встроенные кнопки браузера скрыты;
- отключено меню правой кнопки мыши (в Chrome там пункт «Сохранить видео как…»);
- на iPhone отключено долгое нажатие («Сохранить видео»), запрещено перетаскивание видео;
- HLS и DASH воспроизводятся кусочками, поэтому одного файла для скачивания нет.

**Чего это не даёт (честно):**
- ссылка на видео видна в адресе плеера. Для **MP4** зритель может открыть её напрямую и скачать файл. Для важного контента используйте **HLS**;
- продвинутый пользователь может сохранить поток через инструменты разработчика или расширения браузера.

Настоящая защита — **подписанные ссылки** с ограниченным сроком (Worker в Cloudflare, ≈ $5 в месяц, см. [[R2 + CDN — условия и стоимость]]) или DRM.

## Настройки владельца (внутри файла)

В начале скрипта, блок `CONFIG`:

| Настройка | Сейчас | Зачем менять |
|---|---|---|
| `defaultBase` | `https://cdn.astakhova.com.ua` | адрес для короткой записи `?v=` |
| `allowedHosts` | `[]` — **любые сайты** | ограничить, с каких сайтов можно воспроизводить. Например `["cdn.astakhova.com.ua", "*.b-cdn.net"]` |
| `hlsLib`, `dashLib` | jsDelivr, hls.js 1.6.15, dash.js 4.7.4 | обновить версии библиотек |
| `lang` | `uk` | язык по умолчанию |

> ⚠️ Пока `allowedHosts` пустой, кто угодно может сделать ссылку на ваш плеер с **чужим** видео, и оно откроется на вашем домене. Если плеер будет использоваться только для своих видео, впишите туда свои домены.

**Безопасность ссылок.** Плеер принимает только `https://` (на `http://`-страницах ещё и `http://`). Ссылки вида `javascript:` и `data:` отклоняются, а `title` выводится только как текст, без HTML.

## Сообщения об ошибках

| Сообщение | Причина |
|---|---|
| «Відео не вказано» | нет `src` или `v` |
| «Це посилання не підтримується» | не `https://`, запрещённый сайт (`allowedHosts`) или некорректная ссылка |
| «Не вдалося завантажити відео» | файла нет по ссылке, сайт не отдаёт видео другим доменам (CORS) или нет сети |

> Для HLS и DASH с чужих сайтов сервер должен разрешать загрузку с вашего домена: заголовок CORS `Access-Control-Allow-Origin`. У нашего R2 это уже настроено. MP4 работает и без CORS.
