# Универсальный плеер: параметры (props)

Один HTML-файл (`index.html`) плюс необязательный файл настроек (`player.config.js`). Воспроизводит видео **с любого сайта**: Cloudflare R2, Bunny, S3, свой сервер и т.д. Что показывать и как, задаётся параметрами в адресе страницы. Встраивается на любой сайт через iframe.

Связанные заметки: [[brif|Бриф]] · [[video-r2-instrukciya|Инструкция: видео в R2]] · [[Скрипт prepare_video.sh — описание]] · [[R2 + CDN — условия и стоимость]]

---

## Файлы

| Файл | Что это |
|---|---|
| `index.html` | сам плеер. Править его не нужно |
| `player.config.js` | настройки владельца, необязательный. Включает короткие ссылки `?v=` для вашего Cloudflare R2 |
| `embed-example.html` | пример встраивания через iframe с командами и событиями |
| `v1/`, `v2/` | прошлые версии |

## Один плеер, два способа указать видео

| Способ | Что нужно | Пример |
|---|---|---|
| **`src=`** — полная ссылка | ничего: работает и без `player.config.js`. Любой хостинг, HLS, MP4, WebM, MOV | `index.html?src=https://example.com/video.mp4` |
| **`v=`** — короткая ссылка | `player.config.js` с `defaultBase` (ваш CDN на Cloudflare R2) | `index.html?v=amm/urok-zakritij-kanal` |

Если `player.config.js` рядом с плеером нет, ссылки с `?v=` показывают ошибку «ссылка не поддерживается», а `src=` работает как обычно.

### Другой аккаунт Cloudflare

- Через `src=` — ничего менять не нужно. Подойдёт ссылка из любого аккаунта (свой домен бакета R2, `r2.dev`, Cloudflare Stream). Для HLS на том бакете должен быть настроен CORS (`GET, HEAD`, заголовок `Range`).
- Чтобы короткие ссылки `?v=` вели в другой аккаунт, поменяйте `defaultBase` в `player.config.js`. `?v=` работает только с одним доменом.

## Что умеет воспроизводить

| Формат | Как распознаётся | Выбор качества | Чем играет |
|---|---|---|---|
| **HLS** (`.m3u8`) | по расширению или `type=hls` | да | hls.js (загружается, только если нужен); на старых iPhone — встроенный плеер |
| **Файл**: MP4, WebM, MOV, OGG | всё остальное или `type=file` | нет (одно качество) | встроенный плеер браузера |

**DASH (`.mpd`) убран** в версии от 21.11.2026: HLS работает в тех же браузерах и на iPhone. Версия с DASH лежит в `v3/`.

**Не подходят:** ссылки на страницы YouTube, Vimeo, Google Drive, Telegram и т.п. Нужна прямая ссылка на `.m3u8` или `.mp4`.

## Параметры

| Параметр | Пример | По умолчанию | Что делает |
|---|---|---|---|
| **`src`** | `src=https://…/master.m3u8` | — | **ссылка на видео** (обязательно, если нет `v`) |
| `v` | `v=amm/urok-zakritij-kanal` | — | короткая запись: плеер добавит адрес из `defaultBase` и `/master.m3u8`. Работает, только если `defaultBase` задан в настройках |
| `type` | `type=hls` / `file` | авто | указать формат явно, если в ссылке нет расширения |
| `poster` | `poster=https://…/cover.jpg` | — | обложка до запуска. С настройкой `autoPoster` для `…/master.m3u8` плеер сам ищет рядом `poster.jpg` |
| `title` | `title=Урок 2. Воронка` | — | название в верхней части плеера и во вкладке браузера |
| `t` (или `start`) | `t=90`, `t=1:30`, `t=1m30s` | — | начать с нужного момента |
| `autoplay` | `autoplay=1` | выкл. | запустить сразу. Браузеры разрешают это только **без звука** |
| `muted` | `muted=1` | выкл. | начать без звука |
| `loop` | `loop=1` | выкл. | повторять по кругу |
| `speed` | `speed=1.25` | `1` | начальная скорость, от 0.25 до 4 |
| `accent` (или `color`) | `accent=e3262f` | белый | цвет прогресса, отметок в меню и фавикона, HEX без `#` |
| `lang` | `lang=uk` / `ru` / `en` | язык браузера, запасной `en` | язык подписей и сообщений |
| `resume` | `resume=0` | вкл. | запоминать место, где зритель остановился (`0` — отключить) |
| `seek` (или `noseek`) | `seek=0`, `noseek` | вкл. | `seek=0` — режим «только старт / стоп», без перемотки. Ссылка может только запретить перемотку, но не разрешить её, если она запрещена в настройках |
| `embed` | `embed=0` | в iframe включается сам | без скруглённых углов |
| `fit` | `fit=cover` | `contain` | `cover` — заполнить рамку целиком с обрезкой краёв |

Включить флаг можно и без значения: `&autoplay&muted`. Выключить — `=0`, `=false` или `=off`.

### Важно про ссылки внутри `src`

Если в ссылке на видео есть свои параметры (`?token=…&expires=…`), её нужно **закодировать**, иначе плеер решит, что это его собственные параметры:

```
❌ index.html?src=https://site.com/video.m3u8?token=abc&expires=123
✅ index.html?src=https%3A%2F%2Fsite.com%2Fvideo.m3u8%3Ftoken%3Dabc%26expires%3D123
```

Закодировать можно в консоли браузера командой `encodeURIComponent("ссылка")`.

## Встраивание через iframe

Все параметры из таблицы выше передаются в адресе iframe:

```html
<iframe src="https://ваш-сайт/player/index.html?src=https%3A%2F%2Fcdn.example.com%2Fvideo%2Fmaster.m3u8&title=Урок%202"
        style="width:100%;aspect-ratio:16/9;border:0"
        allow="autoplay; fullscreen"></iframe>
```

Для вертикального видео: `aspect-ratio:9/16`. Без `allow="fullscreen"` не заработает кнопка полного экрана, без `allow="autoplay"` — `autoplay=1` и команда `play`.

Рабочий пример: `embed-example.html`.

### События от плеера

Плеер сообщает странице, на которую он встроен, что происходит:

```js
window.addEventListener("message", function (e) {
  if (e.source !== iframe.contentWindow || !e.data || e.data.source !== "uniplayer") return;
  // e.data = { source: "uniplayer", event: "timeupdate", currentTime: 62.1, duration: 634.6 }
});
```

| Событие | Когда |
|---|---|
| `ready` | видео загрузило метаданные, известна длительность |
| `play`, `pause`, `ended` | запуск, пауза, конец |
| `timeupdate` | раз в секунду во время просмотра |
| `seeked` | зритель перемотал |
| `error` | видео не загрузилось; текст в поле `message` |

Пример: «досмотрел 90% → открыть следующий урок» — сравнить `currentTime / duration` в `timeupdate`.

### Команды плееру

```js
iframe.contentWindow.postMessage({ target: "uniplayer", command: "seek", value: 60 }, "*");
```

| Команда | `value` | Что делает |
|---|---|---|
| `play` | — | запустить (без `allow="autoplay"` браузер может не разрешить до первого клика зрителя) |
| `pause` | — | пауза |
| `seek` | секунды | перейти на момент. Не работает в режиме `seek=0` |
| `mute` | `false` — включить звук | выключить / включить звук |
| `volume` | от 0 до 1 | громкость |

Команды принимаются только от страницы, на которую встроен плеер.

## Управление

| Действие | Мышь / клавиатура | Телефон |
|---|---|---|
| Пуск / пауза | клик по видео, `Пробел`, `K` | кнопка в центре или на панели |
| −10 / +10 секунд | кнопки «10», `←` / `→`, `J` / `L` | двойное касание левой или правой части видео |
| Показать / скрыть панель | движение мыши | одиночное касание |
| Перемотка | клик или перетаскивание по полосе. Переход происходит, когда кнопку отпустили | перетаскивание по полосе |
| Превью кадра | наведение на полосу (**только HLS**; для MP4 показывается только время) | при перетаскивании |
| Громкость | ползунок, `↑` / `↓`, `M` — без звука | кнопкой телефона |
| Полный экран | кнопка, двойной клик, `F` | кнопка |
| Скорость | меню `1×`: 0.5× … 2× | то же |
| Качество | меню настроек (для HLS): Авто / 1080p / 720p … | то же |

Плеер запоминает громкость и место остановки для каждого видео (до конца просмотра).

## Защита от скачивания

**Что сделано:**
- нет кнопки «Скачать», встроенные кнопки браузера скрыты;
- отключено меню правой кнопки мыши;
- на iPhone отключено долгое нажатие («Сохранить видео»), запрещено перетаскивание видео;
- HLS воспроизводится кусочками, поэтому одного файла для скачивания нет.

**Чего это не даёт:**
- ссылка на видео видна в адресе плеера. Для **MP4** зритель может открыть её напрямую и скачать файл. Для важного контента используйте **HLS**;
- продвинутый пользователь может сохранить поток через инструменты разработчика;
- запрет перемотки (`seek=0`) работает только в самом плеере и от технически подкованного зрителя не защищает.

Настоящая защита — **подписанные ссылки** с ограниченным сроком или DRM.

## Настройки владельца (`player.config.js`)

| Настройка | По умолчанию | Зачем менять |
|---|---|---|
| `defaultBase` | пусто (в нашем файле: `https://cdn.astakhova.com.ua`) | адрес CDN для короткой записи `?v=` |
| `allowedHosts` | `[]` — **любые сайты** | ограничить, с каких сайтов можно воспроизводить. Например `["cdn.astakhova.com.ua", "*.b-cdn.net"]` |
| `autoPoster` | `false` (в нашем файле: `true`) | искать `poster.jpg` рядом с `master.m3u8` |
| `seek` | `true` | `false` — запретить перемотку для всех видео |
| `accent` | пусто (белый) | фирменный цвет по умолчанию |
| `lang` | пусто (язык браузера) | язык по умолчанию |
| `hlsLib` | jsDelivr, hls.js 1.6.15 | обновить версию библиотеки или положить её рядом с плеером |

Если `player.config.js` рядом с плеером нет (например, загружен один `index.html`), действуют значения по умолчанию: работает только `src=`.

> ⚠️ Пока `allowedHosts` пустой, кто угодно может сделать ссылку на ваш плеер с **чужим** видео, и оно откроется на вашем домене. Если плеер нужен только для своих видео, впишите туда свои домены.

**Безопасность ссылок.** Плеер принимает только `https://` (на `http://`-страницах ещё и `http://`). Ссылки вида `javascript:` и `data:` отклоняются, а `title` выводится только как текст, без HTML.

## Сообщения об ошибках

| Сообщение (en / uk) | Причина |
|---|---|
| «No video specified» / «Відео не вказано» | нет `src` или `v` |
| «This link is not supported» / «Це посилання не підтримується» | не `https://`, запрещённый сайт (`allowedHosts`), `?v=` без `defaultBase`, ссылка на DASH (`.mpd`) или некорректная ссылка |
| «Could not load the video» / «Не вдалося завантажити відео» | файла нет по ссылке, сайт не отдаёт видео другим доменам (CORS) или нет сети |

> Для HLS с чужих сайтов сервер должен разрешать загрузку с вашего домена: заголовок CORS `Access-Control-Allow-Origin`. MP4 работает и без CORS.
