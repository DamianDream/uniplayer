## 0. Коротко

- **Плеер — это один HTML-файл** без сервера и сборки. Что показывать, он узнаёт из адреса страницы: `index.html?src=<ссылка на видео>&title=…`.
- **Воспроизводит HLS (`.m3u8`), DASH (`.mpd`) и обычные файлы (MP4, WebM, MOV)** с любого сайта, который отдаёт видео по HTTPS и разрешает загрузку с вашего домена (CORS).
- **Cloudflare к плееру не «прикручен».** R2 и `cdn.astakhova.com.ua` — просто место, где сейчас лежат видео. В коде плеера с ними связаны только короткая запись `?v=…` и одна строка настройки `defaultBase`.
- **Сменить провайдера** можно двумя способами: разово (передать в `src` другую ссылку) или целиком (перенести файлы, поменять `defaultBase` и две переменные в скрипте загрузки).
- **Субтитры возможны, в том числе «потоком» внутри HLS.** Проверено: текущий плеер уже показывает субтитры, вшитые в HLS, без доработок. Нужно лишь исправить синхронизацию (сдвиг 1,4 с, решение найдено), добавить кнопку CC и рисовать субтитры над панелью управления.

## 2. Как работает

```
Зритель открывает ссылку  astakhova.com.ua/player-v2/index.html?src=…&title=…
   │
   ├─ 1. Браузер загружает index.html с вашего сайта
   ├─ 2. Плеер читает параметры из адреса: src или v, title, t, autoplay, accent, lang …
   ├─ 3. Проверяет ссылку: только https://, сайт разрешён (allowedHosts), не javascript:/data:
   ├─ 4. Определяет формат: .m3u8 → HLS · .mpd → DASH · остальное → файл (или явно через type=)
   ├─ 5. Подгружает нужную библиотеку (hls.js / dash.js), только если она нужна
   ├─ 6. Библиотека читает плейлист, выбирает качество под скорость интернета
   │     и качает 6-секундные кусочки с CDN
   ├─ 7. Браузер показывает видео; кнопки управления — собственные, кнопки «Скачать» нет
   └─ 8. Место просмотра и громкость сохраняются в браузере зрителя (localStorage)
```

### Какой движок включается

| Формат | Chrome / Edge / Firefox / Android / Mac Safari | iPhone и iPad |
|---|---|---|
| HLS | hls.js, есть меню качества | iOS 17.1+: hls.js (через ManagedMediaSource); старее — встроенный HLS Safari, качество только «Авто». *На реальном iPhone не проверялось* |
| DASH | dash.js, есть меню качества | ⚠️ на старых iPhone не работает. Для iPhone используйте HLS |
| MP4 / WebM / MOV | встроенный плеер браузера | встроенный плеер (WebM — не везде) |

## 3. Условия для работы

### 3.1 Для страницы плеера

- Любой хостинг статических файлов с **HTTPS**: ваш сайт, Webflow (через загрузку файла или iframe), Cloudflare Pages и т.п.
- У зрителей должны открываться `cdn.jsdelivr.net` (библиотеки) и `fonts.googleapis.com` (шрифт). Если где-то они заблокированы, положите библиотеки и шрифт рядом с плеером (раздел 8, пункт G).

### 3.2 Для видео: чек-лист источника

| Требование | Зачем | Для каких форматов |
|---|---|---|
| **Прямая ссылка** на `.m3u8` / `.mpd` / `.mp4`, а не на страницу с видео | плееру нужен сам поток | все |
| **HTTPS** | плеер отклоняет `http://` на https-страницах (браузер всё равно заблокирует смешанный контент) | все |
| **CORS**: `Access-Control-Allow-Origin` — ваш домен или `*`, методы `GET, HEAD`, заголовок `Range` | hls.js и dash.js скачивают кусочки через JavaScript | HLS, DASH, субтитры `.vtt` |
| **Range-запросы** (ответ `206`) | без них в MP4 не работает перемотка. *Проверено в тестах: без Range видео всегда начиналось с нуля* | MP4 |
| **Правильный `Content-Type`** | часть браузеров (особенно Safari) строги к типам | все |
| **Кодеки H.264 + AAC** | работают везде | все |
| Сайт есть в `allowedHosts` (если список заполнен) | ограничение со стороны плеера | все |

Типы файлов: `.m3u8` → `application/vnd.apple.mpegurl` · `.ts` → `video/mp2t` · `.mpd` → `application/dash+xml` · `.m4s` → `video/iso.segment` · `.mp4` → `video/mp4` · `.vtt` → `text/vtt`.

### 3.3 Для зрителя

- Современный браузер с включённым JavaScript.
- Автозапуск (`autoplay=1`) браузеры разрешают **только без звука**, это правило браузеров, а не плеера.

### 4.2 Источники

| Источник | Работает? | Пример ссылки / заметки |
|---|---|---|
| **Наш R2 + `cdn.astakhova.com.ua`** | ✅ **проверено** | `…/amm/urok-zakritij-kanal/master.m3u8`. CORS, кэш и типы настроены |
| Другой бакет R2 со своим доменом | ✅ при условиях из 3.2 | нужен CORS на бакете |

| Mux, api.video и другие видеоплатформы | ✅ если дают публичный HLS | Mux: `https://stream.mux.com/<playback-id>.m3u8` |

## 6. Как подключён Cloudflare

```
Компьютер ── prepare_video.sh ── ffmpeg ──► HLS (1080/720/480, сегменты 6 с, poster.jpg)
                                   │
                                   └─ rclone (S3-ключи токена «Claude R2») ──►  R2: бакет «video»
                                                                                 │  CORS: * GET/HEAD
                                                                                 │  r2.dev: выключен
                                                                                 ▼
                         свой домен cdn.astakhova.com.ua (зона astakhova.com.ua)
                                   │  Cache Rule: кэшировать, срок из Cache-Control (1 год, immutable)
                                   ▼
             Плеер на astakhova.com.ua ──► hls.js ──► зритель
```

| Что | Значение |
|---|---|
| Бакет | `video`, папки `<курс>/<урок>/` |
| Публичный адрес | `https://cdn.astakhova.com.ua` (Custom Domain бакета) |
| Кэш | правило Cache Rules для `cdn.astakhova.com.ua` + заголовок `Cache-Control: public, max-age=31536000, immutable` у каждого файла |
| CORS | `AllowedOrigins: *`, `GET, HEAD`, все заголовки, открыты `Content-Length, Content-Range, ETag` |
| Загрузка | rclone через S3-ключи R2 (хранятся только на вашем компьютере) |
| Управление по API | API-токен «Claude R2» (Workers R2 Storage: Edit) сохранён как секрет облачного окружения Claude, в файлах его нет |
| В самом плеере | **никаких ключей и SDK Cloudflare**. Связь с Cloudflare: `CONFIG.defaultBase = "https://cdn.astakhova.com.ua"` (для `?v=`) и соглашение «рядом с `master.m3u8` лежит `poster.jpg`». Это соглашение нашего скрипта, а не Cloudflare |
| Не путать | `video.astakhova.com.ua` — бакет Telegram-приложения (`tgappastakhova`), к плееру не относится |

## 7. Если понадобится другой провайдер

### 7.1 Разово: одно видео с другого сайта

Код менять не нужно. Передайте полную ссылку в `src` и проверьте чек-лист 3.2 (HTTPS, CORS, Range, типы). Если включён `allowedHosts`, добавьте туда домен.

### 7.2 Переезд целиком (все уроки на новый CDN)

1. **Создать хранилище и CDN** у нового провайдера, настроить CORS, Range, типы файлов, кэш (чек-лист 3.2).
2. **Скопировать файлы, сохранив пути.** rclone копирует между провайдерами напрямую:
   ```bash
   rclone copy r2:video новый-remote:бакет --transfers 16 --progress
   ```
   Исходящий трафик из R2 бесплатный, поэтому переезд ничего не стоит со стороны Cloudflare. После копирования **проверьте `Content-Type` и `Cache-Control`**: не все провайдеры сохраняют их при копировании.
3. **Плеер:** поменять `CONFIG.defaultBase` на новый адрес. Все ссылки вида `?v=amm/…` продолжат работать уже с нового CDN.
4. **Скрипт `prepare_video.sh`:** поменять `REMOTE` (имя rclone-подключения и бакет) и `CDN` (адрес для итоговых ссылок). rclone поддерживает десятки хранилищ (все S3-совместимые: AWS, B2, Wasabi, DO Spaces, GCS и др.).
5. **`allowedHosts`:** заменить домен.
6. **Ссылки с полным `src=` старого CDN** придётся обновить вручную.

> 💡 **Вывод для будущего:** чтобы переезд не ломал ссылки, раздавайте зрителям короткие ссылки (`?v=…`) или ссылки на описание видео (раздел 8, пункт B), а не полные адреса файлов.

### 7.3 Примеры настройки CORS

**R2 / S3 (JSON):**
```json
[{ "AllowedOrigins": ["https://astakhova.com.ua"], "AllowedMethods": ["GET", "HEAD"],
   "AllowedHeaders": ["*"], "ExposeHeaders": ["Content-Length", "Content-Range", "ETag"], "MaxAgeSeconds": 86400 }]
```

**nginx:**
```nginx
location /video/ {
  add_header Access-Control-Allow-Origin "https://astakhova.com.ua" always;
  add_header Access-Control-Allow-Headers "Range" always;
  add_header Access-Control-Expose-Headers "Content-Length, Content-Range" always;
  types { application/vnd.apple.mpegurl m3u8; video/mp2t ts; text/vtt vtt; video/mp4 mp4; }
}
```

## 8. Развитие плеера

Трудоёмкость: **S** — до дня, **M** — несколько дней, **L** — неделя и больше.

### Независимость от провайдера

| # | Идея | Как работает | Польза | Трудоёмкость |
|---|---|---|---|---|
| A | **Пресеты провайдеров** | в `CONFIG.providers` шаблоны: `r2: "https://cdn…/{id}/master.m3u8"`, `bunny: "…/{id}/playlist.m3u8"`, `mux: "https://stream.mux.com/{id}.m3u8"`. Ссылка: `?p=bunny&id=…` | короткие ссылки; переезд — правка одного шаблона | S |
| B | **Описание видео в JSON** | `?m=https://cdn…/amm/urok-02/media.json`. В JSON: список источников (HLS, запасной MP4), постер, название, субтитры, главы | одна ссылка на всё; смена CDN и добавление субтитров без изменения ссылок | M |
| C | **Каталог уроков** | `?id=urok-02` → плеер читает `catalog.json` на CDN (его дописывает `prepare_video.sh`) или спрашивает Worker с базой | самые короткие и постоянные ссылки, основа для «следующего урока» | M |
| D | **Резервный источник (мульти-CDN)** | если первый источник из списка (B) выдал ошибку, плеер переключается на следующий | видео работает, даже если один CDN упал | S (вместе с B) |

Пример `media.json` (идеи B + D + субтитры):
```json
{
  "title": "Урок 2. Воронка продаж",
  "poster": "https://cdn.astakhova.com.ua/amm/urok-02/poster.jpg",
  "sources": [
    { "src": "https://cdn.astakhova.com.ua/amm/urok-02/master.m3u8", "type": "hls" },
    { "src": "https://backup.b-cdn.net/amm/urok-02/master.m3u8", "type": "hls" }
  ],
  "subtitles": [
    { "lang": "uk", "label": "Українська", "src": "https://cdn.astakhova.com.ua/amm/urok-02/subs/uk.vtt", "default": true },
    { "lang": "en", "label": "English", "src": "https://cdn.astakhova.com.ua/amm/urok-02/subs/en.vtt" }
  ],
  "chapters": "https://cdn.astakhova.com.ua/amm/urok-02/chapters.vtt"
}
```

### Защита, аналитика, встраивание

| # | Идея | Как работает | Трудоёмкость |
|---|---|---|---|
| E | **Подписанные ссылки** | ссылка действует N часов и только для одного зрителя. Для R2 — Worker с проверкой подписи (≈ $5 в месяц), у Bunny — Token Authentication, у CloudFront — подписанные cookie, у Stream — подписанные токены. Плеер просто передаёт токен, сама проверка зависит от провайдера | M–L |
| E2 | **Водяной знак** | поверх видео полупрозрачный email или ID зрителя (`&wm=…`). Не мешает смотреть, но отбивает желание записывать экран и делиться | S |
| F | **Аналитика просмотров** | плеер отправляет события «старт, 25 / 50 / 75 / 100%, смена качества, ошибка» в Worker + Analytics Engine/D1 или в Plausible/GA4 | M |
| G | **Свои копии библиотек и шрифта** | положить hls.js, dash.js и Poppins рядом с плеером, без jsDelivr и Google | S |
| H | **API для страницы-хозяина** | плеер в iframe сообщает странице события через `postMessage`: например, «досмотрел 90%» открывает следующий урок | S–M |
| H2 | **Web Component** | `<nl-video src="…">` вставляется на страницу без iframe | M |

### Удобство просмотра

| # | Идея | Трудоёмкость |
|---|---|---|
| I1 | **Главы:** файл `chapters.vtt` → отметки на полосе прогресса и список глав | S–M |
| I2 | **Превью кадров** при наведении на полосу (спрайт миниатюр + VTT, делается тем же ffmpeg) | M |
| I3 | Картинка в картинке (PiP), включить AirPlay/Chromecast как опцию `&cast=1` | S |
| I4 | «Следующий урок» в конце видео (с каталогом C) | S |
| I5 | Запоминать выбранную скорость и язык субтитров | S |

### Конвейер подготовки

| # | Идея | Трудоёмкость |
|---|---|---|
| J1 | **CMAF / fMP4-сегменты:** один набор файлов для HLS и DASH сразу | S–M |
| J2 | Субтитры в скрипте: `SUBS=uk.vtt ./prepare_video.sh …` (см. раздел 9) | S–M |
| J3 | Автоматизация: «положил файл в папку → само нарезалось и загрузилось» (папка-наблюдатель или GitHub Actions) | M |

## 9. Субтитры

**Да, субтитры можно подтянуть, в том числе так, чтобы они шли потоком вместе с видео.** Ниже варианты, результаты проверки и рекомендация.

### 9.1 Варианты

| # | Вариант | Как устроено | Потоком с видео? | Плюсы | Минусы |
|---|---|---|---|---|---|
| 1 | **Отдельный файл WebVTT** | плеер добавляет `<track src="uk.vtt">`; ссылка в параметре `&subs=…` или в `media.json` | нет, файл грузится целиком. Но он крошечный: 50–100 КБ на 45 минут | работает для **любого** формата и провайдера (HLS, DASH, MP4); легко заменить или исправить текст | файл нужно хранить и передавать отдельно; в полноэкранном режиме iPhone поведение нужно проверить |
| 2 | **Субтитры внутри HLS** | в `master.m3u8` строка `#EXT-X-MEDIA:TYPE=SUBTITLES…`, текст нарезан на кусочки `.vtt`, как видео | **да** | субтитры «едут» вместе с видео; работают везде, где играет HLS: Safari, iPhone в полноэкранном режиме, VLC, Smart TV; несколько языков; одна ссылка на всё | нужна правка скрипта; есть ловушка с синхронизацией (решена, см. 9.2) |
| 3 | **DASH: текстовая дорожка** | отдельный AdaptationSet (WebVTT или TTML) в `.mpd` | да | аналог варианта 2 для DASH | нам не нужен, пока основной формат — HLS |
| 4 | **CEA-608/708 внутри видеопотока** | субтитры зашиты в сам поток H.264 (как в ТВ) | да | поддерживаются hls.js и Safari | **CEA-608 не поддерживает кириллицу**, 708 сложно создавать; неудобное оформление. ❌ Не подходит |
| 5 | **Вшитые в картинку (burn-in)** | ffmpeg рисует текст прямо в кадре | да, это часть картинки | видны везде, даже в соцсетях и при записи экрана | нельзя выключить; на каждый язык — отдельная копия видео (×2 хранилища); перекодирование при любой правке текста |
| 6 | Дорожка субтитров в MP4 (`mov_text`) | текст внутри MP4-файла | да | — | браузеры в основном её не показывают. ❌ Вместо неё — вариант 1 |

### 9.2 Что проверено (20.11.2026, на тестовых роликах)

| Тест | Результат |
|---|---|
| ffmpeg упаковывает WebVTT в HLS (`-c:s webvtt` + `sgroup:subs` в `var_stream_map`) | ✅ создаются `master.m3u8` с `SUBTITLES`, плейлист субтитров и кусочки `.vtt` |
| **Текущий плеер v2 показывает такие субтитры без доработок** | ✅ hls.js сам подхватывает дорожку и включает её |
| Синхронизация «как есть» | ❌ **субтитры опережали видео на ~1,4 с.** Видео в MPEG-TS начинается не с нуля (`start_time = 1.4 s`), а ffmpeg не пишет в `.vtt` метку `X-TIMESTAMP-MAP` |
| Синхронизация с исправлением | ✅ строка `X-TIMESTAMP-MAP=MPEGTS:126000,LOCAL:00:00:00.000` в каждом `.vtt` (126000 = 1,4 с × 90 000) → субтитр, задуманный на 4,0 с, появился на 4,02 с |
| Отдельный `.vtt` через `<track>` на MP4 | ✅ показывается и попадает во время |
| Внешний вид | ⚠️ стандартные субтитры браузера **наезжают на панель управления**, когда она открыта. Нужна своя отрисовка (9.4) |

### 9.3 Откуда брать субтитры

| Способ | Украинский | Стоимость | Заметки |
|---|---|---|---|
| Вручную (Subtitle Edit, Aegisub) | ✅ | время | точнее всего, но долго |
| **Whisper локально** (whisper.cpp, faster-whisper) | ✅ (модель многоязычная) | бесплатно | на выходе сразу `.vtt`; для точности — модель large-v3 |
| Cloudflare Workers AI (`whisper-large-v3-turbo`) | язык задаётся кодом, качество для украинского не проверено | по тарифу Workers AI | возвращает WebVTT; удобно автоматизировать в Worker |
| Cloudflare Stream: автоматические субтитры | ❌ **украинского нет** в списке (есть 12 языков, включая русский) | в тарифе Stream | только для видео, загруженных в Stream. Нам не подходит |
| Перевод на другие языки | — | — | готовый `.vtt` переводится через LLM (например Claude) с сохранением таймкодов |

> Автоматические субтитры всегда нужно вычитывать: имена, термины, названия курсов.

### 9.4 Рекомендация

**Основной путь — вариант 2 (субтитры внутри HLS)** для наших уроков. **Запасной — вариант 1 (отдельный `.vtt`)** для MP4 и чужих источников. Плеер поддерживает оба через общий слой текстовых дорожек.

**Что доработать в плеере** (S–M):
1. Параметр `&subs=uk:<ссылка>,en:<ссылка>` (и поле `subtitles` в `media.json`).
2. Кнопка **CC** в правой группе: меню «Выкл. / Українська / English», выбор запоминается.
3. **Своя отрисовка:** дорожка в режиме `hidden`, текущая фраза выводится в собственный блок над панелью управления и поднимается, когда панель видна. Шрифт Poppins, полупрозрачная подложка, размер под экран.
4. Для HLS — список `hls.subtitleTracks` в меню CC, переключение через `hls.subtitleTrack`.

**Что доработать в `prepare_video.sh`** (S–M):
1. Опция `SUBS=uk.vtt` (несколько языков: `SUBS="uk:uk.vtt en:en.vtt"`).
2. Надёжный способ упаковки, без зависимости от особенностей ffmpeg для трёх качеств:
   - положить `.vtt` целиком в `subs/uk.vtt`, добавив вторую строку `X-TIMESTAMP-MAP=MPEGTS:<старт TS × 90000>,LOCAL:00:00:00.000`;
   - создать маленький плейлист `subs/uk.m3u8` из одного сегмента:
     ```
     #EXTM3U
     #EXT-X-TARGETDURATION:2649
     #EXT-X-PLAYLIST-TYPE:VOD
     #EXTINF:2648.68,
     uk.vtt
     #EXT-X-ENDLIST
     ```
   - в `master.m3u8` добавить строку дорожки и `SUBTITLES="subs"` к каждому качеству:
     ```
     #EXT-X-MEDIA:TYPE=SUBTITLES,GROUP-ID="subs",NAME="Українська",LANGUAGE="uk",DEFAULT=YES,AUTOSELECT=YES,URI="subs/uk.m3u8"
     #EXT-X-STREAM-INF:BANDWIDTH=…,RESOLUTION=1920x1080,…,SUBTITLES="subs"
     ```
3. Загружать `.vtt` с `Content-Type: text/vtt`.
4. Опционально: `--auto-subs` — запустить Whisper по звуковой дорожке и сохранить черновик `.vtt` на вычитку.

**Стоимость:** субтитры весят 50–100 КБ на урок и добавляют 2–3 запроса на просмотр. На счёт это не влияет.

## 11. Что проверено к этому моменту (19–20.11.2026)

- HLS (3 качества), MP4, DASH (2 качества), короткая запись `?v=`, `autoplay`, `t`, языки, цвет, фавикон.
- Защита ссылок: `javascript:`, `data:`, HTML в `title` — отклоняются или выводятся текстом.
- Нет меню правой кнопки, нет кнопки «Скачать».
- Жесты на эмуляции iPhone: двойное касание ±10 с, одиночное — панель.
